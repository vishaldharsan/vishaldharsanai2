# 🤖 Vishal Dharsan AI

A personal AI assistant interface built with **HTML, CSS, and JavaScript**.

Vishal Dharsan AI uses a modern futuristic UI with Jarvis-style animations and connects with an AI model through API.

---

## ✨ Features

- 🤖 Personal AI assistant interface
- 🔐 Password lock screen
- 🌌 Futuristic Jarvis HUD animations
- ⚡ Neon glowing UI
- 💬 Chat interface
- ✍️ AI typing animation effect
- 📱 Mobile responsive design
- 🚀 Fast browser-based operation

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Groq API
- Llama AI Model
